## 📂 &nbsp;Projets

### 🧠 &nbsp;[Quantification INT8 d'un ResNet-18 — CIFAR-10](https://github.com/taha588/optimisation/tree/main/quantization)

Compression d'un réseau convolutif par **quantization statique post-entraînement** *(mode FX graph, calibration sur 1 000 images)*, puis mesure du compromis mémoire / précision. La comparaison avec la quantization dynamique montre pourquoi la PTQ statique est indispensable sur un CNN.

> **Résultat** &nbsp;·&nbsp; compression **×3,96** — 42,70 Mo → 10,78 Mo *(−74,8 % de mémoire)* pour **−3,79 points** d'accuracy *(84,65 % → 80,86 %)*

**Stack** &nbsp; `Python` · `PyTorch` · `torch.ao.quantization` · `torchvision` · `NumPy` · `Matplotlib`

### 🗺️ &nbsp;[Requêtes géospatiales dans MongoDB — index `2dsphere`](https://github.com/taha588/projets-data-enginier/tree/main/projet-20-geospatial-mongodb)

Scénario de livraison *(type Glovo)* qui met en œuvre les opérateurs `$near`, `$geoWithin`, `$geoIntersects` et l'agrégation `$geoNear` sur des données **GeoJSON**, avec une carte interactive pour explorer les résultats.

> **Résultat** &nbsp;·&nbsp; benchmark **avec vs sans index** : passage d'un `COLLSCAN` *(scan complet)* à un parcours d'index géospatial

**Stack** &nbsp; `Python` · `MongoDB` · `PyMongo` · `Flask` · `Docker Compose` · `Leaflet`

### 🤝 &nbsp;[Assistant Handicap Global](https://github.com/taha588/assistante) &nbsp;·&nbsp; [🌐 démo](https://assistante.vercel.app)

Chatbot multilingue qui renseigne les personnes en situation de handicap sur les **programmes, droits et ressources** disponibles dans leur pays.

> **Particularité** &nbsp;·&nbsp; agent contraint à répondre dans la langue de l'utilisateur, avec des garde-fous explicites sur le conseil juridique

**Stack** &nbsp; `TypeScript` · `React 19` · `Vite` · `API Gemini` · `Vercel`
